# 基础题集 v2 验证

## 调整原因

原五分钟预览的第一题要求完整的 Unicode 组合符号处理。同一模型在多个 harness 下采用 `U+0300–U+036F` 的有限范围，漏掉 `U+1AB0`，因而同得 11/12。这是有效的边界检查，但不适合作为确认基本读写、修改和命令执行的入门题。

内置题集 v2 使用新的 `slug-basic` 作为首题：只处理 ASCII 字母、数字和空白，完成去除首尾空白、小写转换和合并内部空白。提供 `check.cjs`，公开全部六个验收用例，并要求修改后运行 `node check.cjs`。独立评分直接检查函数输出；修改自测脚本不能制造通过结果。

快速检查仍是三题：基础文本格式、交易文件处理、多文件发票修复。原 `slug` 的 Unicode 检查完整保留在七题 Standard 中。题集版本升级为 `camellia-bench-2`，历史报告使用原题目与成绩，界面显示每份报告的内置题集版本。
