# Camellia v0.1.0 — Windows preview

Camellia brings DeepSeek Harness, Claude Code, and Kimi Code into one desktop workbench with shared API configuration and settings.

## Highlights

- A common home screen, English interface, and centralized engine settings.
- Folder workspaces and standalone Claude/Kimi conversations, with pinning, renaming, branching, archiving, and history.
- Provider presets, bulk key import, model discovery, connection validation, and automatic failover between routes serving the same model.
- Usage statistics by provider, key, model, and date, plus balances and quota trends for supported account APIs.
- Bundled DSH, Kimi, Node.js, npm, and pnpm. The official Claude runtime is downloaded on first use; a separate global CLI installation is not required.
- Reorganized source directories and documentation in English and Simplified Chinese.

## Downloads

This preview provides **Windows x64** builds:

| File | Use |
| --- | --- |
| `Camellia-Setup-0.1.0-win-x64.exe` | Installer with installation-directory selection and shortcuts; recommended for regular use |
| `Camellia-0.1.0-win-x64-portable.zip` | Extract once and launch `Camellia.exe` without installing the application |
| `SHA256SUMS.txt` | SHA-256 checksums for both downloads |

These preview builds are unsigned. Windows may display an unknown-publisher warning.

Install Git for Windows with Bash for engine shell tools. An internet connection is needed for model APIs and the first Claude runtime download.

Both builds use the standard application-data directory, `%APPDATA%/dsh-desktop`. The portable build does not move settings and histories into its own folder. Keep the full extracted folder together, including its bundled runtimes.

## Setup

Open **Settings → Providers & Keys**, add a provider and key, select models, and validate the connection. Return home and choose an engine to start a session.

Saving native engine settings updates the corresponding CLI's global configuration. Existing files receive a one-time `.workbench.bak` backup.

## Platform scope

macOS ARM64 runtime paths, packaging configuration, and a native CI job are included in the source. Native macOS validation is still pending, so this preview includes Windows downloads only.
