# Camellia v1.0.1

Camellia 1.0.1 includes Windows and Android updates, with macOS and native iOS source/build workflows targeting the same version. This note also describes local macOS/iOS outputs; it does not confirm that all platform assets have been published. The iOS client still has parity and device-validation work listed in `ios/WORKPLAN.md`, including discussion groups and math rendering.

## What's New

- Added a native iOS client for iPhone and iPad (iOS 15 or newer): local provider chat plus remote control of paired desktop conversations, with edge-swipe back navigation, page-wide transitions, and native iOS 26 glass where available (iOS 15–25 uses a material fallback).
- Added LaTeX math rendering on desktop and Android, including inline equations, fractions, sums, and matrices, with improved streaming Markdown rendering.
- Added conversation work panels and mobile subtask controls, and enabled multi-model discussions on macOS.
- Added Codex reset-credit visibility and Antigravity sign-out, and improved subscription quota and pricing displays.
- Improved Android history browsing with pagination for older messages and quick navigation back to the latest messages.
- Added default download folders, background downloads, and automatic filename numbering on Android. The iOS client downloads into a user-chosen folder with persistent bookmarks and collision-numbered filenames.
- Added the option to let Camellia manage externally installed CLIs, with improved reinstall and update workflows.
- iOS remote conversations now use capability-gated request receipts, incremental snapshots, stopping during preparation, and server-side list search with pagination.
- Power-saving mode and Reduce Transparency now fall back to opaque menus instead of translucent ones.
- Improved data migration, file previews, model routing, reasoning controls, and subscription quota displays.

## Fixes

- Fixed Codex chat startup and automatic conversation naming, with better fallback model selection.
- Improved archive synchronization, Codex history synchronization, remote connection recovery, and active conversation forks.
- Fixed migration progress display, download folder permission handling, and battery saver menus.
- Simplified empty conversation screens and mobile download actions.

SHA-256 checksum files are provided for all downloads. The Android APK is signed with the release key. Windows executables are not Authenticode-signed, and the macOS app is ad-hoc signed and not notarized, so its first launch needs Gatekeeper approval. The iOS package is unsigned and must be sideloaded or re-signed.

For installation and pairing steps, see the [Android guide](https://github.com/chengwang96/Camellia/blob/main/android/README.md), the [iOS guide](https://github.com/chengwang96/Camellia/blob/main/ios/README.md), and the [remote access guide](https://github.com/chengwang96/Camellia/blob/main/docs/remote-access.md).
