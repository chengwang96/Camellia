# Native harness tool-call audit — 2026-09-16

This historical audit tested the native tool integration of Claude Code 2.1.270, Codex CLI 0.147.0, DSH 0.1.5-rc.1 (headless and ACP chat), Kimi Code 0.43.0, and Antigravity SDK 0.1.16. The model endpoint was a local fixture; real native tools edited disposable workspaces. These were integration tests, not paid model benchmarks.

## Defects and repairs

1. **Antigravity streaming arguments.** Interleaved JSON chunks from two tool calls could cause the second argument to become `{}`; an emoji split across chunks could turn into replacement characters. The Antigravity-specific route `/compat/antigravity/v1/chat/completions` now buffers each reply's tool arguments until complete, while text still streams. It preserves call IDs, names, signatures, finish reason, and usage; incomplete arguments are never submitted to native tools. Reports label this path `buffered-tool-arguments-v1`.
2. **Claude approvals.** The session had a `can_use_tool` handler but did not start the CLI with `--permission-prompt-tool stdio`. The launch now connects that channel. A local test confirmed allowed writes succeeded and denied writes left no file. Benchmark keeps its explicit unattended policy.
3. **Missing tool failure evidence.** Benchmark had listened only for `gui:tool`, missing some Claude and DSH results and errors before execution. It now also associates executed API tool results with call IDs, deduplicates UI events, and stores bounded recent failures. A recovered tool failure does not add a score penalty beyond independent task checks.
4. **Kimi ACP upstream errors.** Kimi 0.43.0 could return `stopReason: end_turn` after an HTTP 400 from the model endpoint. Benchmark now checks the final tool-bearing model request after cleanup so an unrecovered API error outranks an apparent native success. This is a benchmark safeguard; the Kimi runtime itself was not changed, and ordinary chat still depends on native error reporting.
5. **Codex fallback patches.** The previously repaired third-party-model catalog now exposes native `apply_patch`, avoiding a Windows batch wrapper that truncated multiline patches. See the [Codex patch audit](benchmark-codex-patch-2026-09-16.md).

The full local tool round-trip made nine calls per entry (54 in all), covering reads, creation, edits, command and edit failures, filename and content searches, permissions, cancellation, Unicode, and punctuation. More tests covered session restore/fork, a local Antigravity MCP echo, routing protocols, usage, and same-model failover. The local Node and native integration suite passed; real Google/Kimi/ChatGPT sign-ins, paid search, arbitrary user MCP servers, and scheduled agents were outside this audit. Existing historical benchmark scores were not recalculated.

Run `npm run test:tools`, `node tests/tools-native-audit.cjs --permissions`, `node tests/tools-native-audit.cjs --permissions --allow`, and `node tests/tools-native-audit.cjs --upstream-error` with the pinned native runtimes installed. Local evidence files live under ignored `dist/tools-native-audit*.json`; their fake credentials are not user account credentials. A missing runtime must not be treated as a passing native test.
