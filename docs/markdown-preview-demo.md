# 右侧栏 Markdown 预览样例

这个文件用于手工验证右侧栏的 8 项修复。每一节都写明了应当看到的结果。

## 1. 裸文件名不再被当成网址

下面这些名字应保持普通文本，不能点击：

README.md · setup.sh · main.rs · notes.markdown · config.yaml

真正的主机名仍应可点击：

example.com · www.example.com

## 2. 邮箱与 mailto

两者都应可点击，并交给系统邮件客户端：

[发送邮件](mailto:demo@example.com) · demo@example.com

## 3. 本地绝对路径

三种写法都应指向本地文件，而不是显示成纯文本：

[正斜杠盘符](C:/Code/Camellia/docs/artifact-previews.md)

[反斜杠盘符](C:\Code\Camellia\docs\artifact-previews.md)

[显式 file URL](file:///C:/Code/Camellia/docs/artifact-previews.md)

网络共享应被拦截，保持纯文本：

[网络共享](file://server/share/secret.txt)

## 4. 视频语法

应显示可播放的视频控件，而不是损坏的图片：

![演示片段](markdown-preview-demo/demo-clip.mp4)

## 5. 图片

应正常显示，宽度不超过侧栏：

![Camellia 图标](../assets/icon-256.png)

## 6. 代码块与行号定位

从聊天里点击本文件第 52 行，应定位到下面的代码块。

```js
const answer = 42;
console.log('line 52 target');
```

## 7. 跨文件锚点

点击后应打开目标文件，并滚动到对应章节：

[跳到配置文档的账号章节](artifact-previews.md#several-accounts-of-one-provider)

## 8. Anchor Case Test

下面两个链接都应跳到本节，只有大小写不同：

[当前文件内的小写锚点](#anchor-case-test) · [当前文件内的混合大小写锚点](#Anchor-Case-Test)
