# Codex patch retries in a Kimi K3 preview

In the 2026-09-16 report `9d64f4e6-bb4a-4307-863b-fb947e9e18eb`, Codex CLI 0.147.0 using Ollama Cloud `kimi-k3:cloud` passed the first two preview tasks, then timed out on the invoice task without modifying its files. The task had about 119 seconds available; 15 requests used 229,808 reported tokens, and repeated tool calls returned malformed-patch errors. The saved change set was empty. Reported tokens included retransmitted and cached context, so this record cannot establish excessive reasoning as the cause.

The integration defect was a patch transport path. Codex's fallback catalog for an unknown third-party model did not register its native `apply_patch` tool, although instructions still asked for it. On Windows, calls then passed multiline patches through a batch wrapper, where arguments could be truncated. Camellia now supplies a catalog entry for such models that enables Codex's native patch tool, while retaining fallback model defaults. Native Codex still parses and authorizes patches; the Responses bridge carries the complete patch in one JSON string. Known native models, account mode, and explicitly configured catalogs are unchanged.

Local tests reproduced the broken batch path and verified native patches with Unicode, spaces, quotes, backticks, dollar signs, streaming arguments, permission denial, continuation, and cancellation. The diagnostic rerun used only Codex, the same model and three tasks, and scored 12/12, 2/2, and 11/11 in 28.477, 41.200, and 36.298 seconds; it had no tool failure or timeout. Report `54312eae-4ba7-4916-bb1c-c5e40a63ec68` is stored under `dist/benchmark-audit/live-1789553407422/` and did not overwrite the original report.

Reproduce the live diagnostic with `node scripts/benchmark-live-audit.cjs --use-configured-api --preview --codex-only --model=kimi-k3`; this uses provider quota. The deterministic evidence is that the same valid patch failed through the batch path and succeeded through the native tool. The single-engine rerun had different concurrency and cannot attribute every timing difference to the fix or rank Codex against other harnesses.
