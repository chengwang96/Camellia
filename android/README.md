# Camellia Android

可安装的原生 Android 客户端，使用 Android 原生 View（Java），不是 WebView 或网页壳。支持 Android 8.0 / API 26 及以上。沿用桌面浅色/深色配色、圆角、字体层级和消息布局，随系统切换主题及中英文。

## 当前范围

### Android Lint 局部豁免依据

#### 会话菜单验证环境与真机验收

Windows 上的 Emulator 37.1.11 在本机会话菜单测试中曾发生宿主 `qemu-system-x86_64-headless.exe` 的 `0xc0000005` 崩溃，不能将 ADB 中断或空的失败报告当成应用断言失败。当前验证使用 `-gpu host -feature -Vulkan -no-snapshot -no-window -no-audio`；软件渲染重试仍曾崩溃。该配置是本机验证环境的规避方案，不改变应用的磨玻璃、截图或菜单逻辑，也不代表已确定模拟器崩溃的底层原因。

`ConversationMenuTest` 输出阶段标记，保留截图、置顶、重命名、多选、取消删除与确认删除的检查。测试会清空本机会话存储，仅允许在可丢弃模拟器运行；不要在个人手机运行整套仪器测试。

真机验收使用同签名 APK 覆盖安装，不卸载、不清除数据。连接 USB 并授权调试后先用 `adb devices -l` 确认设备；如有多台设备，所有命令必须指定 `-s <serial>`。在手机中新建专用测试会话，再检查长按四项菜单、置顶顺序、重命名持久化、多选取消以及只删除测试会话。远程控制需手机和电脑登录同一 Tailnet 并已有配对，使用专用测试工作区验证重命名、置顶、批量删除与下载；最后手动切换 Wi-Fi／蜂窝、切后台和锁屏，核对恢复后无重复消息、历史未丢失、下载状态明确。不以模拟器回环网关联调代替真机网络验收。

不关闭全局检查，也不使用 baseline 隐藏新问题。纯 Java 创建且需要业务参数的 `ArtifactMessageView`、`ChatChoiceRow`、`ConversationRow`、`PageTransitions`、`PopupSurface` 仅豁免 `ViewConstructor`，不提供无法正确初始化的 XML 构造器。

会话菜单、本地模型选择和远程设置浮层以屏幕左上角计算绝对坐标，背景采样使用同一坐标；仅在定位方法／构造器豁免 `RtlHardcoded`，保留 `Gravity.LEFT`。`PopupCoordinatesTest` 检查 LTR／RTL 下的锚点对齐和可见边界。图片关闭按钮仍固定在物理右上角，其方向性告警暂保留，避免未经设计确认改变交互。

`RefreshScrollView.onTouchEvent` 通过 `finishPull` 间接调用 `performClick`，另提供可发现的无障碍刷新动作，仅对此方法豁免 `ClickableViewAccessibility`；测试检查取消不点击、松手仅点击一次、动作可发现及忙碌时不重复刷新。Manifest 的三个 Activity 保留旧版 `onBackPressed` 导航行为，仅局部豁免 `UnusedAttribute`；旧系统忽略 `enableOnBackInvokedCallback` 属预期兼容行为。

文案格式化与单色主题图标列为后续改进，相关告警不隐藏；文案迁移需尊重应用内语言设置，单色图标需单独制作透明轮廓而非复用彩色位图。

### 设置表单与弹层统一

添加／编辑供应商及模型与密钥页面允许截图。API Key 输入始终显示圆点（包括刚键入的最后一位），已有密钥仅显示脱敏尾号；掩码不等于加密，截图仍会包含供应商名称、Endpoint、模型及密钥尾号。可显示完整明文密钥的 JSON 导入窗口继续禁止截图。

设置输入框统一采用浅色白底／深色抬高底色与常驻细描边，聚焦时使用蓝色描边，错误状态保留行内提示。协议选择、供应商表单、模型与密钥、连接与命名输入共用相同配色。通用选项、表单、确认与电脑连接弹窗统一为 30 dp 圆角底部面板，使用相同拖柄、标题字号、侧边距、遮罩和键盘避让；模型选择等锚定磨玻璃面板保持原有样式。

### 会话长按菜单

本地聊天与远程控制的会话列表移除右侧「⋯」和长按拖动排序。长按会话，在会话附近显示「重命名、多选、置顶／取消置顶、删除」四项菜单。直接复用模型选择面板的 `PopupSurface`：26 dp 圆角、12 dp 背景模糊、相同深浅色半透明蒙层与 8 dp 阴影；旧 Android 或省电模式使用相同的不透明降级方案。多选后点击会话切换选择，顶部可取消或批量删除；删除需要确认。本机置顶保存在加密存储中，远程置顶与电脑端同步，在所属工作区内优先展示。

远程重命名、置顶和删除需要更新并重启电脑端及控制权限。操作按请求 ID 持久化并支持查询重试，发送前验证全部目标的授权、会话版本和忙碌状态；批量删除不是跨会话事务，若执行中发生错误，应先刷新核对结果，不自动重发。删除会永久移除电脑端会话记录，不删除工作区文件。原有归档记录仍可由设置恢复，本机聊天详情页保留归档入口。

### 本地与远程聊天交互统一

两种模式共用底部输入区：模型与思考等级统一显示在输入框下方，发送、停止和键盘发送行为保持一致。本地联网工具、远程图片与安全级别按模式提供，模型参数、权限校验和停止任务语义仍由各自后端决定。顶部显示会话标题和来源，本地模型浮层改为向上展开。

共用会话行与模型／思考等级选项行，保留各自菜单能力。编辑上一条消息时显示可取消的编辑提示；本地与远程草稿同时保存编辑目标，返回会话后继续编辑，清空文字仍保留编辑状态，点击取消才退出编辑。本地生成中的回复也以 Markdown 展示，合并短时间内的更新；在底部跟随输出，向上阅读时保留位置。

### 后台下载与产物面板（v0.3.39）

用户选择保存位置后由 `dataSync` 前台服务下载，切换应用、退出聊天页面及锁屏不再主动中断；通知栏显示进度并提供取消，下载期间保留内置网络和限时唤醒锁。一次只下载一个文件，令牌仅在进程内传递，不写入服务 Intent 或任务文件。系统保存位置选择器仍保留，以确保用户控制文件位置。通知被拒绝时可回 App 查看进度；强制停止、进程被系统终止、网络切换／断线、电脑撤销访问和系统后台服务时限仍可能中断，需要重新下载，不支持断点续传或重启恢复。取消／失败尝试删除未完成文件，无法删除时提示手动清理。

### 产物下载入口（v0.3.38）

远程聊天右上角显示文件夹图标和「产物」文字；已完成回复中引用 APK、文档等常用文件时，正文下方提供「查看会话产物 · 下载到手机」入口。消息入口仅为文件引用提示，不把任意路径当成可下载文件；点击后仍由电脑端鉴权并列出已验证的现有产物。选择产物的「下载到手机」，在系统选择器中选择 Downloads 等位置并点击「保存」，下载完成后在手机文件管理器查看。正文中的代码路径不是直接下载链接。空列表和接口失败提示给出检查范围及更新电脑端的建议。

### 连接后预加载（v0.3.37）

电脑状态检查成功后立即获取会话列表首页，再以独立串行队列优先预加载该页最近活跃的十个会话的最新历史页。用户两秒没有触摸或按键操作后，继续逐个预加载其余会话，并按需翻页发现其他会话；空闲请求至少间隔半秒，新操作会延后后续空闲请求。进入会话列表及列表更新时也会补充预加载，一分钟内未变化的内容和已取列表分页不重复请求。只发只读 GET，不提前发送已读标记或操作命令。开始其他页面请求、切网或切后台时取消预加载，优先保证当前操作；会话详情重新连接成功后恢复空闲预加载。

打开已缓存会话先显示「预加载内容」，实时连接随后替换为最新快照；缓存不授予发送／停止／审批权限，也不展示缓存中的审批和运行中状态。内容按电脑地址与配对凭据隔离，只保存在当前 Activity 内存中，不写磁盘；不再限制六个会话或三份一批，空闲时可逐步遍历所有可访问会话。每份仍限约两百万字符，总缓存按设备堆上限的 1/16 设置为八百万至三千二百万字符，超出时淘汰最久未使用内容，避免会话数量增长耗尽内存。历史全文、图片和产物不自动下载。退出 Activity 清空；撤销授权、拒绝访问、会话不可用或移除电脑时清理相应内容。

### 连接失败原因（v0.3.36）

电脑状态、列表同步和实时重连提示区分：手机断网、内置网络需要登录／管理员批准／尚未就绪、建连超时、响应头超时、读取超时、目标拒绝连接、网络不可达以及电脑端 HTTP 错误。错误附带稳定诊断码和操作建议；外部网络无法确定超时阶段时显示通用超时，不猜测电脑离线或凭据失效。点按底部单行状态栏查看完整、可选择复制的详情。原生桥只输出白名单错误码，不显示原始 URL、令牌或服务端错误正文；无法判定时明确显示原因未知。内置网络登录失效不会删除电脑配对，既有 HTTP 401 撤销处理保持不变。

### Wi-Fi／蜂窝网络切换恢复（v0.3.35）

监听 Android 默认网络及 IP／路由变化，合并短时间内的通知后在工作线程关闭旧内置网络节点，下次请求用原有加密身份重新建立节点。前台电脑列表、会话列表和聊天页自动重新同步；后台只清理旧连接、不主动同步，返回前台时再次核对默认网络。忽略已切离网络的迟到断网通知；断网显示等待恢复，未确认命令保留原请求 ID，不自动重发。文件下载中断后需手动重试。建连和响应头的总等待上限调整到 30 秒，底层单次拨号限制为 25 秒，为出门切换到流量时的网络恢复留出时间。真实手机蜂窝链路仍需实际验收。

### 远程连接恢复（v0.3.33）

短暂切后台时立即取消页面请求和事件订阅，但未发生网络切换时内置网络节点保留最多五分钟，减少返回时重新建连；不保活系统进程，也不在后台同步会话。内置请求可在等待连接／响应头时取消；已建立的实时订阅不受建连总等待上限限制，仍保留读空闲超时。新版电脑端将权限、工作区和会话列表一次返回，避免首次同步串行查询状态；订阅初始游标与已同步列表一致时不再重复拉取。旧电脑端自动回退查询状态，兼容已有配对。

### 远程聊天多图附件（v0.3.32）

相册支持一次多选，也可继续追加照片，每条消息最多 9 张图片。附件以输入框内横向滚动的圆角缩略图显示，每张右上角的关闭按钮仅移除该图片，不再提供单独的「移除图片」按钮。读取图片期间禁用发送，明确发送失败时恢复完整图片列表；结果不确定时仍复用原请求，避免重复发送。图片压缩后每张不超过 1 MiB，多图发送需更新并重启电脑端；旧版电脑端仍兼容单图发送。

### 远程操作即时反馈

- 远程聊天首屏及历史分页提升到最多 200 条原始记录、约 1 Mi 字符预算（含执行过程，需更新并重启电脑端）。手机最多保留约 600 条／4 Mi 字符历史。聊天顶部继续下拉并松手可加载更早消息，也保留按钮入口；请求期间显示同款菊花动画并防止重复请求，加载后保持原消息阅读位置，失败可重试，无更多历史时关闭下拉加载。

聊天页采用右侧浅色用户气泡、左侧 Agent 正文布局。本机 API 返回的公开思考文本与最终回答分开保存；开启联网工具后也显示本机工具输入、结果和状态。远程会话显示电脑同步的过程文字、思考、计划和工具输入 / 结果 / 状态。执行过程默认折叠，运行中可手动展开，更新保留展开状态，回合结束自动收起，重新进入历史时默认收起；最终回答始终显示在折叠框外。API 未返回思考文本时不伪造过程。远程过程需要同时更新并重启电脑端；旧会话无法补回此前未保存的思考文本。仅同步已授权会话中的展示字段，不下发原始事件、签名、引擎配置或工具请求的隐藏元数据。

### 本机独立聊天

#### 受限联网工具

本机会话顶部的搜索图标打开「联网工具」，默认关闭，需按会话主动开启。当前提供无 Key 的受限 `web_search` 和 `web_fetch`，可搜索公开网页并读取已知的公开 HTTPS 页面；不支持终端、文件操作、任意代码或 MCP。无需电脑在线，不修改桌面端。

- 搜索优先读取 Bing 的轻量 RSS 结果（通常仅数 KiB），不可用时尝试百度 HTML，不需要任何搜索 Key；最多返回 5 条标题、公开 URL 和摘要。模型供应商仍须支持 function calling。RSS 使用禁用 DTD 和外部实体的安全 XML 解析；百度回退依赖网页结构，仍可能因网络屏蔽、限流、验证码或页面改版暂时失效。同一轮失败后提示模型不要重复重试。
- 网页读取仅限公开 HTTPS、443 端口，禁止凭据 URL、回环、内网、Tailnet、链路本地、保留地址；DNS 返回混合地址时只保留公开地址建立连接，禁用代理和自动重试。最多跟随 3 次仍须通过同样安全检查的公开 HTTPS 重定向。不会向目标网页发送 Cookie 或模型 Key，也不执行页面脚本。普通网页单次最多读取 512 KiB，搜索结果页最多 2 MiB，20 秒超时，正文截取 12,000 字符。需要 JavaScript 或登录的网页可能失败。
- 开启即授权本会话发起只读联网请求：搜索词发送给 Bing 或百度，目标网站可见网页读取请求的 IP，结果回传当前模型供应商。搜索结果和网页内容均标为不可信资料，不能赋予模型新工具或权限；多轮模型调用仍可能产生额外费用。
- 工具模式第一期使用非流式 JSON，每轮完整收到并校验参数后才执行；普通聊天保持流式。OpenAI-compatible 和 Anthropic Messages 均支持，当前循环在内存中保留工具调用 ID、结果和所需思考字段／签名。供应商不遵守 `stream=false`、不支持工具或返回截断调用时停止，不静默降级或重试。
- 每条消息最多执行 8 轮工具、16 次调用，随后关闭工具并要求模型基于已有搜索摘要和网页结果完成回答，避免在已有资料可用时以轮数上限错误结束；总时限仍为 3 分钟。搜索摘要足以回答时不要求逐页抓取，网页无可读正文时提示模型使用搜索摘要且不要重复抓取。结果在「执行过程」展示并加密保存，成功返回的 HTTPS 来源追加到回答末尾。停止、切后台、进程重启不会自动重放工具；重启后运行中记录标记已中断。后续用户消息沿用文字聊天历史，不重放完整原始工具协议。

测试使用本机模拟 API 和假工具执行器，覆盖两种协议、调用关联、来源、搜索结果解析、未知工具、参数错误、次数／轮数限制、取消、内网地址拦截、无密钥配置和开关 UI；未使用付费模型完成端到端真实公网搜索验收。

本机与远程聊天采用更舒展的正文行距与段落间距；每条消息下方提供整条正文复制按钮和本地时区时间（用户右对齐、Agent 左对齐）。本机与远程聊天均可点击最后一条用户消息气泡或正文进入编辑模式，修改后点击发送，从该条消息开始替换并重新生成后续回复，不追加为新消息；远程使用与电脑端相同的 `editSeq` 重发逻辑，不撤销已执行的文件操作。回复运行中不可编辑，远程还需控制权限且消息未被截断。清空输入再重写仍保持编辑模式，离开会话后保留编辑草稿与目标；输入栏的取消按钮可退出编辑。复制保留 Markdown 原文，不混入执行过程。新本机消息持久化发送 / 回复开始时间；旧本机消息没有时间记录时不显示时间，避免伪造历史时间。

本地与远程会话列表的长按手势仅用于打开菜单，不再触发移动、排序或拖动预览；现有会话顺序与工作区归属保持不变，可通过置顶调整展示优先级。

2. 也可粘贴电脑或手机导出的完整 JSON；手机端不读写配置文件。导入前完整校验，只替换 API 配置，不删除聊天记录。使用兼容桌面的 `camellia-api-routes` v2 格式，支持空配置、停用配置往返；桌面订阅登录、电脑工作区路径和聊天记录不会导入。「复制导出」需确认明文密钥风险，剪贴板标记为敏感内容，过大配置拒绝复制。

支持 OpenAI-compatible Chat Completions 和 Anthropic Messages 的文字对话、流式回复、Markdown 展示、停止和草稿保存。沿用供应商 / 模型协议覆盖和 upstream 映射，保留所有已启用且不重复的密钥。仅在生成前收到明确认证 / 额度拒绝（401、402、429，含明确认证 / 套餐错误的 JSON 403，或其他 4xx JSON 中明确的 insufficient_quota、quota_exceeded、余额不足、月额度耗尽等信息）时，按列表顺序尝试同一供应商的下一把密钥，每把最多一次；不会跨供应商发送，不重试普通 403/405、上下文长度错误、网络失败、5xx 或已开始的回复。HTML 网关与地区 / IP 限制不触发换 Key。每次新请求仍从首个启用 Key 开始，耗尽月额度的 Key 可手动关闭，额度恢复后再开启。错误详情显示经过密钥脱敏的服务商 JSON 信息和尝试次数。远程 API 必须是 HTTPS；HTTP 仅允许手机本机回环地址，桌面配置中的 localhost 在手机上指向手机自身。

- 显示连接失败、授权撤销、会话不再可见；支持移除本机凭据。
- 后台停止连接，不承诺后台通知，不在手机执行引擎或代码。

**支持发送、停止和工具审批。** 电脑端确认授权后即可操作，无需另设只读／控制权限；旧设备在新版电脑端加载时自动统一为控制权限。新配对请同步更新 Android 客户端，以支持控制权限的配对响应。支持新建会话、文字和单张图片发送、停止当前运行、单次允许/拒绝工具请求，不改变引擎权限模式。需要填写答案的交互问答、超长审批详情暂时必须回电脑处理。二维码、非图片附件尚未实现；最多缓存约 600 条 / 4 Mi 字符历史。

Agent 历史回复和流式回复使用原生 Markdown 渲染：标题、粗体/斜体、删除线、嵌套列表、引用、分隔线、行内代码、代码块及 GFM 表格。宽表格和长代码可横向滚动，表格支持列对齐和单元格内格式；代码块带语言标签及复制按钮，正文可选择复制，适配深浅主题。用户消息保留原文。使用 CommonMark Java 0.21.0，不使用 WebView，不执行 HTML/脚本，不自动加载远程图片；仅允许 HTTP(S) 链接并在打开浏览器前确认。LaTeX、Mermaid、HTML 表格和代码语法高亮暂不支持。极深嵌套或过多块/单元格的消息回退到完整纯文本，避免创建过多原生 View。

发送前在 Keystore 加密存储中记录请求 ID 和正文；网络中断后，连接恢复时点击对话区域的 **未收到确认** 提示重试，不在输入框下方另设按钮，也不会自动换 ID 再发。其他操作可点击状态提示重试。桌面持久化幂等记录，重启后不重复执行结果不明的操作；此时应先核对会话再决定下一步。停止绑定服务实例和运行 ID，审批还绑定具体请求内容。电脑或手机先处理后，另一端失效；授权降级或撤销会立即断开事件流。

## 安装与配对

进入「远程控制」立即检查已配对电脑的连接，连接成功后后台预取该电脑的工作区与首批独立／工作区会话并加密缓存。再次打开该电脑的工作区／会话页面时先显示上次缓存，同时立即同步最新列表；暂时断网仍保留缓存，缓存不代表当前在线或拥有操作权限。缓存按电脑地址和配对令牌隔离，移除电脑或发现授权失效时清除。

列表采用轻量线框图标与缩进标题，顶部显示 Camellia 和电脑名称；工作区右侧可以新建会话，底部搜索框旁可新建独立会话。搜索按标题匹配，会继续读取授权范围内尚未加载的分页。独立会话统一排在工作区之后。列表搜索栏和会话输入栏使用相同的底部基线，并为状态文字及系统导航预留空间。

远程会话列表在标题右侧显示「正在运行」「等待电脑处理」及「新消息」，通过现有实时同步更新；运行中也可以同时显示尚未阅读的回复。新消息以电脑记录的已完成回复为准，手机或电脑打开会话并成功显示内容后，共享已读状态，另一端同步清除提醒；已读记录保存在电脑，重启后保留，后续新回复仍会再次提醒。此功能需要更新手机端并更新、重启电脑端；连接旧电脑版本时保留手机本地已读记录。断网时状态来自上次缓存，以底部连接提示为准。

**新建会话和图片发送需要同步更新并重启电脑端源码。** 新建前选择执行引擎，沿用电脑端连接设置；授权范围之外不可新建。输入框左侧「+」选择一张图片，发送前可预览或移除，压缩为最长边不超过 1600 像素、1 MiB 内的 JPEG。电脑将图片保存到远程操作日志旁的 `mobile-images` 目录（总额上限 256 MiB），交给会话引擎；这些文件用于后续会话历史，不自动删除。图片内容是否能被理解仍取决于引擎/模型。新建和发送均保存请求 ID，断网重试不会重复执行。

远程会话与本机聊天一致：点击最后一条用户消息（气泡或正文）进入编辑模式，发送后改为 `resend` 请求，从该条消息开始替换并重新生成后续回复；消息正文本身可被选中，因此正文也绑定点击。仅最新一条用户消息可编辑，运行中、有待确认操作或没有控制权限时不进入编辑。电脑仍会校验 `editSeq` 必须是当前最新用户消息且 `expectedSeq` 与电脑会话序号一致，不满足时按拒绝处理并保留草稿。

远程输入框的未发送内容按会话保存在手机本地的加密凭据中：退回会话列表、离开应用或重启后再进入同一会话时，草稿会回到输入框；发送成功后清除，电脑拒绝发送时恢复原内容。未完成的编辑会连同编辑目标一起保存，重新进入后仍是编辑而不是新消息。草稿不会同步到电脑，也不改变电脑端自己的草稿。

移动端从首页进入「远程控制」，管理已配对电脑、查看连接状态，通过电脑卡片右侧菜单重命名或移除。点击电脑进入工作区/独立会话列表，再点击会话查看内容、发送、停止及审批（需要电脑授权）。返回键逐级返回，沿用统一横向转场。列表顶部下拉刷新，连接状态统一显示在底部搜索栏或会话输入栏下方，保留 8 dp 间距，单行显示，过长时以省略号收尾，不遮挡边沿和阴影。本机与远程会话列表／聊天页的底部额外留白统一为 8 dp，状态文字上下内边距各为 2 dp，搜索栏和输入栏较原布局下移约 28 dp；系统导航与键盘安全区仍单独保留。底部状态栏可点按打开「状态与错误详情」，本机聊天与远程控制行为一致，详情保留异常链路并支持选择、复制；远程 HTTP 失败附带经令牌、Bearer 和密钥脱敏的服务端正文。读屏用户仍可读取完整状态文字，并通过列表的「刷新」无障碍操作更新。

首页「设置」包含「供应商与 Key」「通用」「已归档」「手机访问」四项。通用支持语言（系统 / 中文 / 英文）、外观（系统 / 浅色 / 深色），仅影响手机；已归档支持恢复或确认后永久删除本地会话，远程归档仍由电脑端管理；手机访问即原有内置 Tailscale / 外部 VPN 网络配置。本地会话详情页的管理菜单可归档，运行中的会话须先停止；归档当前会话时自动打开同一分组的相邻会话，分组内已无会话则在该分组新建会话，独立会话同理，归档其他会话不影响当前会话。

设置采用浅灰底、白色大圆角分组、居中标题、圆形返回按钮、线形图标与缩进分隔线；深色模式使用对应深灰层级。通用设置以右侧次级文字展示当前值，保持原有四个功能入口，不增加订阅或账号功能。

设置子页沿用相同的分组层级：供应商使用标题、Endpoint 说明和右侧蓝色开关，模型 / 密钥与配置迁移以列表行进入；手机访问分为连接、网络与隐私、关于，说明文字收纳在对应卡片或卡片下方；归档会话按卡片展示恢复与删除操作。危险操作使用红色文字并保留确认，不新增记忆、订阅等功能。

所有页面的顶部返回按钮共用 48 dp 圆形按钮、轻柔阴影与按压下沉效果，兼容深浅主题。远程控制的电脑选择页在顶部按钮旁直接显示「远程控制」，不显示 Logo、产品名或重复的大标题。

支持保存多台电脑，名称仅在手机本地生效。旧版单电脑凭据自动兼容，全部电脑令牌及未确认操作仍通过 Keystore 加密保存，切换电脑不会混用。点击「远程控制」、电脑列表回到前台或下拉刷新时，所有电脑卡片立即显示「正在检查…」，使用独立线程池最多同时检查 4 台电脑，并逐台更新结果，不等待全部检查完成。离开页面会取消检查并清除排队任务，旧结果不会覆盖新一轮状态；无法连接不等同于电脑已离线。

手机停留在会话列表且连接正常时，电脑新建或删除授权范围内的会话会自动触发同步，无需下拉刷新。连续变化约 250 ms 合并推送，已加载的分页与分组折叠状态保留；后台暂停连接，回前台或断线重连后重新同步。

v0.3.1：会话按工作区分组，可点击分组标题折叠/展开，折叠状态按电脑保存在本机。独立会话有单独分组，需要电脑授权「独立会话」或「全部允许」。分页加载会合并到已有分组，刷新不会丢失折叠设置。界面沿用桌面的猫咪标志、蓝色强调、浅色/深色中性色、圆角控件与引擎标签。

电脑端授权统一包含当前及未来新增的全部工作区和独立会话，无需勾选范围。旧版部分授权设备可在设备卡片点击「授权全部访问」并确认，手机刷新即可，无需重新配对。

1. 安装调试 APK（本地构建后在 `app/build/outputs/apk/debug/app-debug.apk`；交付副本在仓库 `dist/Camellia-Android-debug.apk`）。这是自用测试签名，不是商店发布包。
2. 电脑在 Camellia「设置 → 手机访问」开启内置网络并登录；手机打开 Camellia 的内置网络设置登录同一 Tailnet，两端均无需另外安装 Tailscale。手机也可手动选择外部模式。
3. 运行含远程网关的新桌面源码，打开 **设置 → 手机访问 → 配对与设备管理**，开启访问并勾选工作区（“手机访问”位于“空间清理”下方，应用菜单和托盘也保留手机访问入口）。
4. 生成配对码，将面板显示的完整地址（例如 `http://100.80.1.2:43127`）和配对码输入 App。
5. 手机点击 **请求配对**，再在电脑点击 **授权设备**，手机最多约五秒后自动进入会话列表。
6. 锁屏或切后台后连接暂停；回到 App 自动恢复。电脑须开机、联网且 Camellia 未退出。

配对码失效或请求响应丢失时，在电脑重新生成配对码。等待审批状态安全存储，正常重启可以继续领取。撤销设备须在电脑完成；手机“移除电脑”只删除手机凭据。

电脑远程连接地址严格限制为 `100.64.0.0/10` 的规范 IPv4、HTTP 和明确端口；不接受域名、普通局域网、用户信息、路径、查询或片段。内置模式直接通过用户态 Tailscale 加密隧道发送请求；外部模式依赖用户另行连接的 VPN。请只填写可信电脑显示的地址。远程电脑请求不经过系统 HTTP 代理、不跟随重定向，也不把令牌放进 URL。Manifest 允许 cleartext，电脑连接由 `Endpoint` 限制地址；本机聊天 API 地址另由 `LocalChatConfig` 校验，仅允许 HTTPS 或本机回环 HTTP，且不跟随重定向。内置网络的开源许可随 APK 打包，可在网络设置中阅读。

## 构建与测试

位置默认不读取、不随消息发送。用户点击发送明确涉及本人当前位置的问题（如「推荐附近餐厅」「我在哪里」）时，会先显示一次性确认，并说明接收方；只有选择「允许本次」后才申请 Android 大致位置权限。即使系统已经授权，每条相关消息仍需确认。仅请求前台单次网络定位，最多等待 10 秒，不申请精确或后台位置权限，不读取历史缓存；坐标保留两位小数并注明至少 2 km 不确定性。拒绝、关闭系统定位或超时会在不提供位置的情况下继续，让模型必要时询问城市；取消发送或离开页面会停止定位且不发送。中文／英文意图匹配仅用于建议，可能漏掉复杂表达，不代表用户同意。位置不提供实时天气或商家查询能力。

本机聊天仅把位置附加到本次 API 请求，不写入本机用户消息；供应商仍可能保存请求，回答也可能提及位置。远程聊天会将位置随本次消息发送给电脑及其模型服务商，并进入电脑会话历史（后续模型上下文可能包含该历史），确认框会提醒。默认没有全局自动定位开关。

「设置 → 通用 → 键盘回车」提供三种手机本地偏好，本机和远程聊天共用：默认回车发送、长按换行；回车换行、长按发送；仅点击发送按钮（回车始终换行）。发送沿用按钮的可用状态，不绕过运行中、待确认或空消息等限制。能提供按下／松开事件的键盘在松开时区分短按与长按，重复事件不会重复发送；只提供编辑动作或换行提交的软键盘仅能识别短按，无法可靠区分长按，可改用回车换行和发送按钮。多行粘贴不会触发发送。设置即时用于后续输入，不改变电脑端偏好。

模型选择使用圆角磨玻璃浮层，选中项仅以蓝色勾选标识。进入思考等级后保留并淡化父菜单，支持标题返回、点击露出的父层或系统返回逐级收起；确认选项会关闭整个菜单。Android 12 及以上在硬件加速、非省电模式下，两级面板直接采样背后的聊天页面，在页面绘制时更新内存中的局部低分辨率背景，使用 12 dp 模糊与约 26%–40%（深色 40%–50%）遮罩，保留背景轮廓和色彩，不再叠加采样父菜单的白底。父菜单退后时使用 6 dp 失焦。背景不保存到磁盘，关闭浮层时移除监听并释放图像；旧系统与省电模式使用实色面板。菜单内容保持清晰，系统关闭动画时不播放浮起动画。本机和远程聊天的输入／搜索容器采用统一柔和阴影，输入聚焦时保留蓝色边界。设置分组、项目缩进保留现有结构，不额外叠加玻璃材质。

手机页面使用统一的 iOS 风格横向转场：进入网络连接、本机聊天、电脑会话列表及聊天详情时从右侧推入，返回时向右退出，底层页面以 30% 位移跟随，时长为 320 ms。页面刷新和旋转恢复不播放转场；系统关闭动画时尊重系统设置。标题栏返回和 Android 系统返回使用相同的页面层级。

版本号仅在用户明确要求安装、发布或指定版本时统一调整；日常修改、测试和重新打包不自动递增 `versionName` 或 `versionCode`。当前版本为 v0.3.32，内部 `versionCode` 为 37，包含远程聊天多图附件及缩略图关闭按钮。进入远程控制时立即检查连接并预取工作区与首批会话，再次进入该电脑时先展示加密缓存并立即同步最新列表，同时包含远程操作即时反馈优化。继续同步远程会话详情页标题；远程新建会话首条消息自动命名的修复还需更新并重启电脑端。保留编辑框上方的渐变半透明过渡与下方的不透明遮挡。联网功能页面采用与应用一致的圆角卡片和主题开关，并精简为 Bing、百度及公开网页说明。本机聊天支持点击最后一条用户消息进入编辑模式并重新生成后续回复；无 Key 受限 `web_search` 优先使用 Bing 轻量 RSS、失败时回退百度，工具额度提高到 8 轮、16 次调用，额度结束后基于已有资料生成最终回答。DNS 混合结果仅保留公开地址，并可安全跟随最多 3 次公开 HTTPS 重定向。继续支持 `web_fetch`，不包含 Brave 集成或搜索 Key 配置，同时包含 Ollama Cloud 请求 User-Agent 兼容修复。位置意图覆盖无城市的当前天气查询；本机会话菜单与删除确认采用应用自定义样式；远程聊天添加图片时可选择相册或相机。会话列表底部采用不透明 Dock 与渐变折叠遮挡，搜索框和编辑框增加透明渐变及立体边缘，远程模型、思考等级和权限面板统一为磨玻璃设计。交付包为 `dist/Camellia-Android-0.3.32-debug.apk`，同时更新 `dist/Camellia-Android-debug.apk`。

通用设置中的语言、外观、键盘回车选择框统一为圆角底部面板，沿用设置页的深浅色卡片、勾选标记和独立取消按钮，保留单选无障碍语义；其他确认和编辑弹窗不在本次调整范围。
