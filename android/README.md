# Camellia Android

可安装的原生 Android 客户端，使用 Android 原生 View（Java），不是 WebView 或网页壳。支持 Android 8.0 / API 26 及以上。沿用桌面浅色/深色配色、圆角、字体层级和消息布局，随系统切换主题及中英文。

## 当前范围

聊天页采用右侧浅色用户气泡、左侧 Agent 正文布局。本机 API 返回的公开思考文本与最终回答分开保存；开启联网工具后也显示本机工具输入、结果和状态。远程会话显示电脑同步的过程文字、思考、计划和工具输入 / 结果 / 状态。执行过程默认折叠，运行中可手动展开，更新保留展开状态，回合结束自动收起，重新进入历史时默认收起；最终回答始终显示在折叠框外。API 未返回思考文本时不伪造过程。远程过程需要同时更新并重启电脑端；旧会话无法补回此前未保存的思考文本。仅同步已授权会话中的展示字段，不下发原始事件、签名、引擎配置或工具请求的隐藏元数据。

### 本机独立聊天

本机模型 API 请求使用明确的 `User-Agent: Camellia-Android/LocalChat`，不使用系统默认的 Dalvik 标识。2026-09-23 使用无效测试 Key 对 Ollama Cloud 做同端点对照：Dalvik 标识返回 HTML 403，应用标识返回正常 JSON 401（测试 Key 无效）。该修复避免这类客户端标识拦截，不代表真实 Key、套餐或手机网络已通过验证；仍不对 HTML 403 自动轮换 Key，不伪装浏览器或跟随认证重定向。

#### 受限联网工具

本机会话顶部的搜索图标打开「联网工具」，默认关闭，需按会话主动开启。当前提供无 Key 的受限 `web_search` 和 `web_fetch`，可搜索公开网页并读取已知的公开 HTTPS 页面；不支持终端、文件操作、任意代码或 MCP。无需电脑在线，不修改桌面端。

- 搜索优先读取 Bing 的轻量 RSS 结果（通常仅数 KiB），不可用时尝试百度 HTML，不需要任何搜索 Key；最多返回 5 条标题、公开 URL 和摘要。模型供应商仍须支持 function calling。RSS 使用禁用 DTD 和外部实体的安全 XML 解析；百度回退依赖网页结构，仍可能因网络屏蔽、限流、验证码或页面改版暂时失效。同一轮失败后提示模型不要重复重试。
- 网页读取仅限公开 HTTPS、443 端口，禁止凭据 URL、回环、内网、Tailnet、链路本地、保留地址；DNS 返回混合地址时只保留公开地址建立连接，禁用代理和自动重试。最多跟随 3 次仍须通过同样安全检查的公开 HTTPS 重定向。不会向目标网页发送 Cookie 或模型 Key，也不执行页面脚本。普通网页单次最多读取 512 KiB，搜索结果页最多 2 MiB，20 秒超时，正文截取 12,000 字符。需要 JavaScript 或登录的网页可能失败。
- 开启即授权本会话发起只读联网请求：搜索词发送给 Bing 或百度，目标网站可见网页读取请求的 IP，结果回传当前模型供应商。搜索结果和网页内容均标为不可信资料，不能赋予模型新工具或权限；多轮模型调用仍可能产生额外费用。
- 工具模式第一期使用非流式 JSON，每轮完整收到并校验参数后才执行；普通聊天保持流式。OpenAI-compatible 和 Anthropic Messages 均支持，当前循环在内存中保留工具调用 ID、结果和所需思考字段／签名。供应商不遵守 `stream=false`、不支持工具或返回截断调用时停止，不静默降级或重试。
- 每条消息最多执行 8 轮工具、16 次调用，随后关闭工具并要求模型基于已有搜索摘要和网页结果完成回答，避免在已有资料可用时以轮数上限错误结束；总时限仍为 3 分钟。搜索摘要足以回答时不要求逐页抓取，网页无可读正文时提示模型使用搜索摘要且不要重复抓取。结果在「执行过程」展示并加密保存，成功返回的 HTTPS 来源追加到回答末尾。停止、切后台、进程重启不会自动重放工具；重启后运行中记录标记已中断。后续用户消息沿用文字聊天历史，不重放完整原始工具协议。

测试使用本机模拟 API 和假工具执行器，覆盖两种协议、调用关联、来源、搜索结果解析、未知工具、参数错误、次数／轮数限制、取消、内网地址拦截、无密钥配置和开关 UI；未使用付费模型完成端到端真实公网搜索验收。

聊天左上角模型胶囊按内容收窄，不占满标题栏。按钮使用简称：Kimi K3 → K3、GPT-6-Astra → Astra、GPT-5.6-Sol → Sol、DeepSeek V4 Pro → V4 Pro / R1 → R1；MiMo 保留品牌以免通用版本号混淆，例如 MiMo 2.6 Pro / Flash。未知模型和自定义名称保持原文，过长时省略显示；模型菜单与无障碍说明保留完整名称，请求 ID 与配置不变。

本机与远程聊天采用更舒展的正文行距与段落间距；每条消息下方提供整条正文复制按钮和本地时区时间（用户右对齐、Agent 左对齐）。本机聊天可点击最后一条用户消息气泡进入编辑模式，发送后从该条消息开始替换并重新生成后续回复；回复运行中不可编辑。复制保留 Markdown 原文，不混入执行过程。新本机消息持久化发送 / 回复开始时间；旧本机消息没有时间记录时不显示时间，避免伪造历史时间。

启动页沿用桌面「开始工作」的卡片布局，仅保留「本地聊天」「远程控制」两张卡片和一个设置入口，不显示基准测试。本地聊天与电脑远程会话互相独立：可新建、重命名和移除工作区，新建、搜索、重命名、归档和删除会话；移除工作区会将会话保留为独立会话。

本地与远程会话列表通过「工作区」标题右侧的加号新建工作区；供应商与 Key 统一从设置进入。远程新建需要新版电脑端及「控制所有工作区」授权，填写名称和电脑上已存在文件夹的绝对路径，不创建手机目录。网络中断后可查询 / 重试同一请求，避免重复创建；允许访问独立会话时，即使为空也显示独立会话板块，方便拖入。

本地与远程会话均可长按后拖动，在工作区内调整顺序，或拖到其他工作区标题（包括折叠工作区）改变归属；插入线标明落点，靠近列表边缘自动滚动，返回或离开应用取消拖动。本地会话原长按菜单改由右侧「⋯」打开，顺序与归属加密保存在手机。远程移动需要更新电脑端、控制权限及源和目标工作区授权；请求可查询 / 重试而不会重复执行，顺序与桌面共用，不改变执行目录或移动文件。

长按后会话以约 220 ms 的缓动轻微放大浮起，带柔和阴影并跟随手指；原位置淡出，落点两侧会话以约 180 ms 动画让位，插入提示淡入，取消或松手后恢复。边缘滚动跟随屏幕刷新节奏；关闭系统动画时直接显示最终状态，不强制播放动画。拖动预览只保存在内存，结束后释放。

本机与远程会话共用浅色 / 深色配色、线形图标、圆角按钮和消息样式。工作区使用文件夹、标题后折叠箭头及缩进会话列表；底部统一为搜索胶囊或消息输入栏，发送 / 停止使用 48 dp 图标按钮。保留本机专属的 API 配置、工作区管理和模型 / 思考等级选择；不显示本机尚不支持的附件与远程审批操作。

1. 手机进入「设置 → 供应商与 Key」，手动添加供应商名称、Endpoint、API Key（支持每行一个）和模型 ID（支持 `别名=上游模型`），选择 OpenAI / Anthropic / Dual 协议；已有供应商可编辑、启停、移除。在「模型与密钥」中可逐个开关已有 Key，按编号和脱敏尾号识别，保存后生效、取消不修改；关闭的 Key 保留但不参与请求或重试，全部关闭时供应商模型不可用。编辑时密钥输入留空则保留已有 Key 及开关，填写则整体替换为新 Key。
2. 也可粘贴电脑或手机导出的完整 JSON；手机端不读写配置文件。导入前完整校验，只替换 API 配置，不删除聊天记录。使用兼容桌面的 `camellia-api-routes` v2 格式，支持空配置、停用配置往返；桌面订阅登录、电脑工作区路径和聊天记录不会导入。「复制导出」需确认明文密钥风险，剪贴板标记为敏感内容，过大配置拒绝复制。
3. 新建会话，在顶部选择供应商 / 模型，检查显示的 API 地址后发送。手机直接通过互联网请求 API，不经过电脑或内置 Tailscale，不要求电脑在线；请求会将当前会话上下文发送给所选供应商，可能产生 API 费用。

支持 OpenAI-compatible Chat Completions 和 Anthropic Messages 的文字对话、流式回复、Markdown 展示、停止和草稿保存。沿用供应商 / 模型协议覆盖和 upstream 映射，保留所有已启用且不重复的密钥。仅在生成前收到明确认证 / 额度拒绝（401、402、429，含明确认证 / 套餐错误的 JSON 403，或其他 4xx JSON 中明确的 insufficient_quota、quota_exceeded、余额不足、月额度耗尽等信息）时，按列表顺序尝试同一供应商的下一把密钥，每把最多一次；不会跨供应商发送，不重试普通 403/405、上下文长度错误、网络失败、5xx 或已开始的回复。HTML 网关与地区 / IP 限制不触发换 Key。每次新请求仍从首个启用 Key 开始，耗尽月额度的 Key 可手动关闭，额度恢复后再开启。错误详情显示经过密钥脱敏的服务商 JSON 信息和尝试次数。远程 API 必须是 HTTPS；HTTP 仅允许手机本机回环地址，桌面配置中的 localhost 在手机上指向手机自身。

本机聊天页左上角、返回键右侧的胶囊按钮显示模型和思考等级。点击打开圆角浮层，模型按供应商和 API 域名区分，蓝色勾选标记当前项；「思考等级」进入二级选择页，可选默认、标准、进阶。设置按会话加密保存，切换不同模型后恢复默认，运行中不可更改。默认不添加思考参数；OpenAI-compatible 的标准 / 进阶发送 `reasoning_effort: medium/high`，是否支持取决于供应商。已识别的 Claude 模型按版本使用 adaptive + effort 或 thinking token budget，未知 Anthropic 模型仅开放默认，避免发送臆测参数。进阶可能增加耗时和费用；参数被 API 拒绝时可切回默认，不会自动重发收费请求。

API 密钥、工作区和会话通过 Android Keystore 加密存储，不上传到电脑。粘贴对话框禁用截图及自动填充；剪贴板仍由系统管理，导入后建议清除敏感内容。切后台停止请求，保留已接收文本；中断不会自动重发，返回应用后可以继续聊天。一次仅运行一个本机请求，运行时可以返回本机列表。当前为纯文字聊天，不支持附件、电脑工具 / 代码执行或后台运行；本机历史约限 8 Mi 字符，过长会话需新建或清理。

**v0.3 内置 Tailscale：手机不再必须安装第二个 App。** 打开「内置网络 / Tailscale 登录」，保持内置模式开启，点击登录，在系统浏览器授权加入电脑所在的 Tailnet，返回刷新到 Running 后再完成 Camellia 配对。新版桌面也已内置 Tailscale，在「设置 → 手机访问」开启并授权 `camellia-desktop` 节点，无需另装电脑客户端；使用桌面显示的新地址连接。手机内置节点显示为 `camellia-android`，并非电脑或外部 Tailscale App 的同一节点；访问策略或设备审批需允许它。

内置网络使用 Tailscale `tsnet` 1.98.6 + Go/JNI，全部会话请求通过用户态加密网络拨号，不监听本地代理端口、不创建系统 VPN、不转发其他应用流量。节点状态由 Android Keystore AES-GCM 加密持久化，不嵌入 Auth Key。切后台后立即停止会话流，30 秒后释放网络节点，回前台重建；无后台通知保证。内置模式失败不会自动改为外部直连。网络设置中可手动切换外部模式，或清除本地节点身份；清除不等于服务端撤销，需要在 Tailscale 管理后台另行撤销旧节点。

APK 包含 ARM64（通常的安卓手机）和 x86_64（模拟器），不支持仅 32 位 ARM 的老设备。首次登录需要手机互联网访问 Tailscale 控制服务、浏览器身份认证和可能使用的中继服务。Camellia 不代替你完成账号登录。

- 输入桌面 Tailscale 地址、设备名称、一次性配对码，等待电脑确认。
- Android Keystore AES-GCM 加密持久化设备令牌与待领取凭据；禁用云备份和设备迁移备份。v0.3.1 起允许截图、录屏及最近任务预览，分享前请检查会话正文、配对码等敏感内容。
- 会话列表及分页、历史消息及分页、运行中文本、待审批提示。
- SSE 快照替换，不重复追加；断线退避重连、回到前台重新同步、实例变化清空历史缓存。
- 显示连接失败、授权撤销、会话不再可见；支持移除本机凭据。
- 后台停止连接，不承诺后台通知，不在手机执行引擎或代码。

**支持发送、停止和工具审批。** 电脑端确认授权后即可操作，无需另设只读／控制权限；旧设备在新版电脑端加载时自动统一为控制权限。新配对请同步更新 Android 客户端，以支持控制权限的配对响应。支持新建会话、文字和单张图片发送、停止当前运行、单次允许/拒绝工具请求，不改变引擎权限模式。需要填写答案的交互问答、超长审批详情暂时必须回电脑处理。二维码、非图片附件尚未实现；最多缓存约 300 条 / 2 Mi 字符历史。

Agent 历史回复和流式回复使用原生 Markdown 渲染：标题、粗体/斜体、删除线、嵌套列表、引用、分隔线、行内代码、代码块及 GFM 表格。宽表格和长代码可横向滚动，表格支持列对齐和单元格内格式；代码块带语言标签及复制按钮，正文可选择复制，适配深浅主题。用户消息保留原文。使用 CommonMark Java 0.21.0，不使用 WebView，不执行 HTML/脚本，不自动加载远程图片；仅允许 HTTP(S) 链接并在打开浏览器前确认。LaTeX、Mermaid、HTML 表格和代码语法高亮暂不支持。极深嵌套或过多块/单元格的消息回退到完整纯文本，避免创建过多原生 View。

发送前在 Keystore 加密存储中记录请求 ID 和正文；网络中断时使用 **重试未确认操作**，不会自动换 ID 再发。桌面持久化幂等记录，重启后不重复执行结果不明的操作；此时应先核对会话再决定下一步。停止绑定服务实例和运行 ID，审批还绑定具体请求内容。电脑或手机先处理后，另一端失效；授权降级或撤销会立即断开事件流。

## 安装与配对

列表采用轻量线框图标与缩进标题，顶部显示 Camellia 和电脑名称；工作区右侧可以新建会话，底部搜索框旁可新建独立会话。搜索按标题匹配，会继续读取授权范围内尚未加载的分页。独立会话统一排在工作区之后。列表搜索栏和会话输入栏使用相同的底部基线，并为状态文字及系统导航预留空间。

**新建会话和图片发送需要同步更新并重启电脑端源码。** 新建前选择执行引擎，沿用电脑端连接设置；授权范围之外不可新建。输入框左侧「+」选择一张图片，发送前可预览或移除，压缩为最长边不超过 1600 像素、1 MiB 内的 JPEG。电脑将图片保存到远程操作日志旁的 `mobile-images` 目录（总额上限 256 MiB），交给会话引擎；这些文件用于后续会话历史，不自动删除。图片内容是否能被理解仍取决于引擎/模型。新建和发送均保存请求 ID，断网重试不会重复执行。

移动端从首页进入「远程控制」，管理已配对电脑、查看连接状态，通过电脑卡片右侧菜单重命名或移除。点击电脑进入工作区/独立会话列表，再点击会话查看内容、发送、停止及审批（需要电脑授权）。返回键逐级返回，沿用统一横向转场。列表顶部下拉刷新，连接状态统一显示在底部搜索栏或会话输入栏下方，保留 8 dp 间距，单行显示，过长时以省略号收尾，不遮挡边沿和阴影。本机与远程会话列表／聊天页的底部额外留白统一为 8 dp，状态文字上下内边距各为 2 dp，搜索栏和输入栏较原布局下移约 28 dp；系统导航与键盘安全区仍单独保留。读屏用户仍可读取完整状态文字，并通过列表的「刷新」无障碍操作更新。

首页「设置」包含「供应商与 Key」「通用」「已归档」「手机访问」四项。通用支持语言（系统 / 中文 / 英文）、外观（系统 / 浅色 / 深色），仅影响手机；已归档支持恢复或确认后永久删除本地会话，远程归档仍由电脑端管理；手机访问即原有内置 Tailscale / 外部 VPN 网络配置。长按本地会话可归档，运行中的会话须先停止；归档当前会话时自动打开同一分组的相邻会话，分组内已无会话则在该分组新建会话，独立会话同理，归档其他会话不影响当前会话。

设置采用浅灰底、白色大圆角分组、居中标题、圆形返回按钮、线形图标与缩进分隔线；深色模式使用对应深灰层级。通用设置以右侧次级文字展示当前值，保持原有四个功能入口，不增加订阅或账号功能。

设置子页沿用相同的分组层级：供应商使用标题、Endpoint 说明和右侧蓝色开关，模型 / 密钥与配置迁移以列表行进入；手机访问分为连接、网络与隐私、关于，说明文字收纳在对应卡片或卡片下方；归档会话按卡片展示恢复与删除操作。危险操作使用红色文字并保留确认，不新增记忆、订阅等功能。

所有页面的顶部返回按钮共用 48 dp 圆形按钮、轻柔阴影与按压下沉效果，兼容深浅主题。远程控制的电脑选择页在顶部按钮旁直接显示「远程控制」，不显示 Logo、产品名或重复的大标题。

支持保存多台电脑，名称仅在手机本地生效。旧版单电脑凭据自动兼容，全部电脑令牌及未确认操作仍通过 Keystore 加密保存，切换电脑不会混用。点击「远程控制」、电脑列表回到前台或下拉刷新时，所有电脑卡片立即显示「正在检查…」，使用独立线程池最多同时检查 4 台电脑，并逐台更新结果，不等待全部检查完成。离开页面会取消检查并清除排队任务，旧结果不会覆盖新一轮状态；无法连接不等同于电脑已离线。

手机停留在会话列表且连接正常时，电脑新建或删除授权范围内的会话会自动触发同步，无需下拉刷新。连续变化约 250 ms 合并推送，已加载的分页与分组折叠状态保留；后台暂停连接，回前台或断线重连后重新同步。

v0.3.1：会话按工作区分组，可点击分组标题折叠/展开，折叠状态按电脑保存在本机。独立会话有单独分组，需要电脑授权「独立会话」或「全部允许」。分页加载会合并到已有分组，刷新不会丢失折叠设置。界面沿用桌面的猫咪标志、蓝色强调、浅色/深色中性色、圆角控件与引擎标签。

电脑端授权统一包含当前及未来新增的全部工作区和独立会话，无需勾选范围。旧版部分授权设备可在设备卡片点击「授权全部访问」并确认，手机刷新即可，无需重新配对。

1. 安装调试 APK（本地构建后在 `app/build/outputs/apk/debug/app-debug.apk`；交付副本在仓库 `dist/Camellia-Android-debug.apk`）。这是自用测试签名，不是商店发布包。
2. 电脑在 Camellia「设置 → 手机访问」开启内置网络并登录；手机打开 Camellia 的内置网络设置登录同一 Tailnet，两端均无需另外安装 Tailscale。手机也可手动选择外部模式。
3. 运行含远程网关的新桌面源码，打开 **设置 → 手机访问 → 配对与设备管理**，开启访问并勾选工作区（“手机访问”位于“空间清理”下方，应用菜单和托盘也保留手机访问入口）。
4. 生成配对码，将面板显示的完整地址（例如 `http://100.80.1.2:43127`）和配对码输入 App。
5. 手机点击 **请求配对**，再在电脑点击 **授权设备**，手机最多约五秒后自动进入会话列表。
6. 锁屏或切后台后连接暂停；回到 App 自动恢复。电脑须开机、联网且 Camellia 未退出。

要测试控制功能，请先更新桌面代码并重启桌面，再覆盖安装 v0.2 APK。已有配对不必删除，在电脑 **手机访问 → 已授权设备 → 开启控制** 后手机会自动重连。打开一个已有会话，发送简单指令；运行时可停止，出现工具权限请求时可查看详情并允许一次/拒绝。引擎若处于全自动模式，本身不会弹出审批；请在电脑将测试会话设为需审批的模式。停止不会回滚已经执行的修改。

配对码失效或请求响应丢失时，在电脑重新生成配对码。等待审批状态安全存储，正常重启可以继续领取。撤销设备须在电脑完成；手机“移除电脑”只删除手机凭据。

电脑远程连接地址严格限制为 `100.64.0.0/10` 的规范 IPv4、HTTP 和明确端口；不接受域名、普通局域网、用户信息、路径、查询或片段。内置模式直接通过用户态 Tailscale 加密隧道发送请求；外部模式依赖用户另行连接的 VPN。请只填写可信电脑显示的地址。远程电脑请求不经过系统 HTTP 代理、不跟随重定向，也不把令牌放进 URL。Manifest 允许 cleartext，电脑连接由 `Endpoint` 限制地址；本机聊天 API 地址另由 `LocalChatConfig` 校验，仅允许 HTTPS 或本机回环 HTTP，且不跟随重定向。内置网络的开源许可随 APK 打包，可在网络设置中阅读。

## 构建与测试

位置默认不读取、不随消息发送。用户点击发送明确涉及本人当前位置的问题（如「推荐附近餐厅」「我在哪里」）时，会先显示一次性确认，并说明接收方；只有选择「允许本次」后才申请 Android 大致位置权限。即使系统已经授权，每条相关消息仍需确认。仅请求前台单次网络定位，最多等待 10 秒，不申请精确或后台位置权限，不读取历史缓存；坐标保留两位小数并注明至少 2 km 不确定性。拒绝、关闭系统定位或超时会在不提供位置的情况下继续，让模型必要时询问城市；取消发送或离开页面会停止定位且不发送。中文／英文意图匹配仅用于建议，可能漏掉复杂表达，不代表用户同意。位置不提供实时天气或商家查询能力。

本机聊天仅把位置附加到本次 API 请求，不写入本机用户消息；供应商仍可能保存请求，回答也可能提及位置。远程聊天会将位置随本次消息发送给电脑及其模型服务商，并进入电脑会话历史（后续模型上下文可能包含该历史），确认框会提醒。默认没有全局自动定位开关。

「设置 → 通用 → 键盘回车」提供三种手机本地偏好，本机和远程聊天共用：默认回车发送、长按换行；回车换行、长按发送；仅点击发送按钮（回车始终换行）。发送沿用按钮的可用状态，不绕过运行中、待确认或空消息等限制。能提供按下／松开事件的键盘在松开时区分短按与长按，重复事件不会重复发送；只提供编辑动作或换行提交的软键盘仅能识别短按，无法可靠区分长按，可改用回车换行和发送按钮。多行粘贴不会触发发送。设置即时用于后续输入，不改变电脑端偏好。

模型选择使用圆角磨玻璃浮层，选中项仅以蓝色勾选标识。进入思考等级后保留并淡化父菜单，支持标题返回、点击露出的父层或系统返回逐级收起；确认选项会关闭整个菜单。Android 12 及以上在硬件加速、非省电模式下，两级面板直接采样背后的聊天页面，在页面绘制时更新内存中的局部低分辨率背景，使用 12 dp 模糊与约 26%–40%（深色 40%–50%）遮罩，保留背景轮廓和色彩，不再叠加采样父菜单的白底。父菜单退后时使用 6 dp 失焦。背景不保存到磁盘，关闭浮层时移除监听并释放图像；旧系统与省电模式使用实色面板。菜单内容保持清晰，系统关闭动画时不播放浮起动画。本机和远程聊天的输入／搜索容器采用统一柔和阴影，输入聚焦时保留蓝色边界。设置分组、项目缩进保留现有结构，不额外叠加玻璃材质。

手机页面使用统一的 iOS 风格横向转场：进入网络连接、本机聊天、电脑会话列表及聊天详情时从右侧推入，返回时向右退出，底层页面以 30% 位移跟随，时长为 320 ms。页面刷新和旋转恢复不播放转场；系统关闭动画时尊重系统设置。标题栏返回和 Android 系统返回使用相同的页面层级。

版本号仅在用户明确要求安装、发布或指定版本时统一调整；日常修改、测试和重新打包不自动递增 `versionName` 或 `versionCode`。当前版本为 v1.0.0，内部 `versionCode` 为 34，本版恢复编辑框上方的渐变半透明过渡，同时保留编辑框下方的不透明遮挡。联网功能页面采用与应用一致的圆角卡片和主题开关，并精简为 Bing、百度及公开网页说明。本机聊天支持点击最后一条用户消息进入编辑模式并重新生成后续回复；无 Key 受限 `web_search` 优先使用 Bing 轻量 RSS、失败时回退百度，工具额度提高到 8 轮、16 次调用，额度结束后基于已有资料生成最终回答。DNS 混合结果仅保留公开地址，并可安全跟随最多 3 次公开 HTTPS 重定向。继续支持 `web_fetch`，不包含 Brave 集成或搜索 Key 配置，同时包含 Ollama Cloud 请求 User-Agent 兼容修复。位置意图覆盖无城市的当前天气查询；本机会话菜单与删除确认采用应用自定义样式；远程聊天添加图片时可选择相册或相机。会话列表底部采用不透明 Dock 与渐变折叠遮挡，搜索框和编辑框增加透明渐变及立体边缘，远程模型、思考等级和权限面板统一为磨玻璃设计。交付包为 `dist/Camellia-Android-1.0.0-debug.apk`，同时更新 `dist/Camellia-Android-debug.apk`。

需要 JDK 17、Android SDK Platform 35、Build Tools 35.0.0、NDK 27.2.12479018、Go 1.26.3。先构建固定版本的 Go/JNI 网络库，再构建 Android；AAR 属于生成文件，不提交到仓库。设置 `JAVA_HOME`、`ANDROID_HOME`、`ANDROID_NDK_HOME` 后执行：

```powershell
cd android
.\build-tailnet.ps1
.\gradlew.bat assembleDebug testDebugUnitTest lintDebug
```

Gradle Wrapper 固定为 8.11.1，包含分发包 SHA-256 校验。首次构建需联网下载 Google Maven / Maven Central 依赖。签名仅由 Android 默认 debug keystore 完成；不要用于公开发布。仓库不包含本机 SDK 路径、发布私钥或配对凭据。

构建完成后把产物复制为交付包（`dist/Camellia-Android-<version>-debug.apk` 与 `dist/Camellia-Android-debug.apk`），并在回答中附上 APK 路径或链接。改版本号或交付安装包的那一轮必须同时重新构建 APK，否则本轮产物卡片只会显示被修改的 README 和 Gradle 配置，而不是安装包。

```powershell
adb install -r app/build/outputs/apk/debug/app-debug.apk
adb shell am start -n app.camellia.mobile/.MainActivity
```
