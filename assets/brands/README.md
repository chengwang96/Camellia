# Engine brand marks

Local assets identify the engines integrated into Camellia and are bundled for offline use.

| Asset | Source |
| --- | --- |
| `deepseek.svg` | Whale artwork from `@deepseek-ai/dsh-web-frontend` 0.1.5-rc.2, `dist/favicon.svg`, with a blue fill. [DeepSeek Harness](https://github.com/deepseek-ai/deepseek-harness); see `LICENSE-deepseek`. |
| `claude.svg` | [Lobe Icons Claude mark](https://github.com/lobehub/lobe-icons/blob/master/packages/static-svg/icons/claude-color.svg), MIT; see `LICENSE-lobe-icons`. Checked against the mark on [Claude's official site](https://claude.com/). |
| `codex.png` | Unmodified Codex cloud mark from the official OpenAI desktop app 26.908.4834.0, `webview/assets/codex-app-ga-logo-3e5209898ca3.png`. OpenAI brand artwork, used to identify the Codex integration; not covered by the Lobe Icons license. |
| `kimi.svg` | [Kimi's official brand guide](https://moonshotai.github.io/Branding-Guide/), `scenarios/04-k-only/k-only-color.svg`; supplied white variant for colored backgrounds. |

Product names and brand marks belong to their respective owners. Their use identifies the integrations and does not imply endorsement.

- `antigravity.svg`: Antigravity color mark from [Lobe Icons](https://github.com/lobehub/lobe-icons/blob/master/packages/static-svg/icons/antigravity-color.svg), under the included Lobe Icons MIT license.
